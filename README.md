# NAKA Studio

Адаптивный лендинг по восьмистраничному PDF-макету студии детейлинга.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для статической сборки:

```bash
npm run build
```

Готовый сайт находится в `out/`.

## Публикация

Сайт публикуется на GitHub Pages из ветки `main` через workflow `.github/workflows/deploy-pages.yml`. В настройках репозитория **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. После каждого push workflow соберёт статический сайт и обновит страницу:

https://khrapun.github.io/naka-studio-landing/

Проверки: `npm run typecheck`, `npm run lint`.

## Структура

- `app/` — App Router, метаданные и глобальные стили;
- `components/layout/` — навигация;
- `components/sections/` — восемь экранов лендинга;
- `components/ui/` — окно связи;
- `components/animations/` — появление в viewport и параллакс;
- `lib/content.ts` — данные услуг и отзывов;
- `public/assets/` — фото из PDF и SVG-декор.

Экраны: главная, оклейка, антикоррозийная обработка, тонировка, детейлинг, студия, локации, отзывы. Фотографии и коллаж извлечены из предоставленного PDF. Неоновые дорожки и схема воспроизведены в SVG. Появление заголовка, карточек и секций сделано через Motion for React; лёгкий параллакс фотографий — через GSAP ScrollTrigger. При `prefers-reduced-motion` эффекты выключаются.

## Известные ограничения превью

- В PDF нет отдельных исходных фотографий и геройское фото закрыто красной пометкой «ФОТО КОМАНДЫ». На первом экране временно использован кадр детейлинга из того же PDF. Для окончательного совпадения нужен исходный кадр без пометки.
- Отзывы в PDF содержат частично нечитаемый растровый текст. Тексты в коде — краткая адаптация; перед публикацией их следует заменить подтверждёнными оригиналами.
- В макете не указаны ссылки на Instagram и Telegram. Их иконки открывают контактное окно. Добавьте точные URL после получения от студии.
- Для кнопок записи и отзывов используется WhatsApp/телефон; серверная форма в макете не предусмотрена.
